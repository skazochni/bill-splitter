    О приложении

    Bill Splitter — разделить счёт

    Приложение помогает разделить счёт: по позициям или поровну, со скидкой, налогом и чаевыми, в нескольких валютах. Работает без интернета.

    Данные хранятся только на вашем устройстве (в браузере), сетевых запросов с данными нет.

    Установка

    • Chrome (Android): меню → «Установить приложение».
    • Samsung Internet: меню → «Добавить страницу в» → «Главный экран».
    • Firefox: меню → «Установить».
    • Edge: меню → «Добавить на телефон».
    • Другие браузеры: меню → «Добавить на главный экран».
    • iPhone (Safari): «Поделиться» → «На экран «Домой»».
    Не удалось сохранить данные в этом браузере — расчёт работает, но после перезагрузки сбросится.
